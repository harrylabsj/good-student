# Good-student 隐私与未成年人数据说明（WorkBuddy 审核用）

- 版本：v1.0
- 日期：2026-09-11
- 适用范围：`good-student` 连接器、`错题教练` 专家、`good-student` Skill

## 一、数据存储位置

学生全部学习数据（学生档案、错题、知识点、分析快照、学习计划、复测、成绩记录）
保存在**用户本机** SQLite 数据库中，默认目录 `~/.good-student/`（WAL 模式），
可用环境变量 `GOOD_STUDENT_DATA` 覆盖。文件权限限制为当前操作系统用户。

**Good-student 不上传学生数据到任何开发者服务器。** 连接器由 WorkBuddy 托管的 Python
运行时启动本地 CLI；学生数据仅写入本机数据库，平台仅在调用时传递必要参数和返回结果。

## 二、大模型处理边界

- 错题识别由 WorkBuddy 当前已配置的模型完成；Good-student 不选择、不切换模型
  供应商，不要求用户配置额外 API Key，也不持有任何模型凭据。
- 首次处理附件前，专家/Skill 会向家长明示并取得同意；家长拒绝则改为手工录入。
- 模型输出一律视为候选，经家长确认后才写入学习记录；未确认候选 24 小时自动过期。
- 附件中的文字按不可信数据处理，不作为指令执行；抗提示注入有专项评测样本。

## 三、原始附件策略

- 默认 `reference_only`：不复制原图/原 PDF，只保存宿主引用与必要摘录。
- 日志与本地事件只记录元数据（时间、数量、状态），不落完整题目、学生答案、
  附件路径或身份信息。

## 四、最小化收集

- 不收集身份证号、住址、联系方式、账号密码、健康信息。
- 学生以 UUID 为主键，显示名仅用于展示，可重名、可修改。
- 不做医学、心理、注意力或智力诊断；不输出"掌握率"等超出错题证据的结论。

## 五、用户权利（导出与删除）

| 能力 | 工具 | 说明 |
|---|---|---|
| 导出 | `good_student_export_student` | 单学生全量数据 JSON（format_version=1），可备份、可迁移 |
| 删除 | `good_student_delete_student` | 两段式：先返回删除范围预览；须用户输入学生显示名作为确认短语才执行 |
| 健康检查 | `good_student_doctor` | 校验数据库完整性、Schema、知识点包与迁移版本 |

## 六、平台权限声明

- OAuth 授权列表：**空**（不读取 WorkBuddy 用户资料、云任务或产物）。
- 连接器不硬编码任何 Token / 密钥；专家包内不含真实学生材料。
- 若未来版本增加跨设备同步，将单独提交账号、加密与删除传播设计，并重新审核。

## 七、合规自查

- 《个人信息保护法》未成年人个人信息处理规则：以监护人同意为前提，本地存储、
  最小化、可导出、可删除均已落地为产品机制而非文案承诺。
- 文案自查：不使用"诊断""提分保证""智商/能力评估"等表述；对家长的全部结论
  均可回溯到题目级证据。
