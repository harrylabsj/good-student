# Good-student 错误与降级注册表

| 场景 | 处理 | 用户看到 |
|---|---|---|
| 无附件、空文件、格式不支持 | 不调用模型 | 没有可读取的错题材料 |
| 宿主无视觉/PDF 能力 | 请求文本、可读 PDF 或手工输入 | 明确降级选项 |
| 模型超时、限流、拒绝 | 最多重试一次；不写入失败结果 | 识别暂时失败，数据未写入 |
| 空输出、非法 JSON、Schema 不匹配 | 修复提示重试一次，之后人工录入 | 不展示伪结果 |
| 部分页成功 | 保存成功候选，单列失败页 | 已识别 X/Y 页 |
| 重复上传 | 返回已有批次 | 可继续上次确认 |
| 用户中途退出 | 候选保留至过期 | 尚未进入学习画像 |
| 锁失败、磁盘满、库损坏 | 停止写操作，不覆盖原文件 | 请检查磁盘或运行 doctor |
| 证据不足 | 返回 insufficient_evidence | 暂不能判断，需要复测 |
| 未知科目或知识点 | 保留自定义标签，降低置信度 | 请用户确认 |
