# 真题查漏教练｜海纳-教育专家

独立的 WorkBuddy 收费专家候选，首版覆盖普通高中数学、英语、物理。旧「学生错题本」保持原样。

WorkBuddy 会话中的视觉模型提取脱敏错题，用户确认后才入档。HTTP MCP 从经过签名验证的授权获得账号身份，同一账号只能创建一个学生档案。服务负责归档、从已核验题库选题、判分、保留跨会话练习进度及计算两轮复测状态。主观题只在评分要点齐全且用户确认后计分。复测要求每题独立、每轮至少三题、至少三分之二题满分，两轮通过相隔至少 48 小时。系统尝试按原卷题号去重，并排除已下发及主动标记见过的题。

## 验收

在此目录安装：`python -m pip install -e '.[dev]'`。运行 `python -m pytest -q tests`。测试用临时 RSA 密钥和数据库，通过实际 Streamable HTTP MCP 请求验收身份隔离；不使用真实学生资料。对话层的照片由 WorkBuddy 视觉模型直接处理，测试不模拟平台已经提供视觉能力或订阅回调。

随附的少量高中真题仅用于开发验收。每科至少一组样例（数学：集合与运算；英语：词性与构词；物理：动量与碰撞）。样例经题号和公开参考答案核验，只返回原卷链接及定位，不在聊天里转印题面。部分题卷含参考答案，做题时只看题面。题源可在 `src/exam_coach/source_bank.json` 逐项回查。公开网页没有被视作商业题面授权。

## 云端配置及打包

1. 准备已获授权的题库 JSON，结构与样例一致。经人工核对原卷、答案、考点、难度和题面完整性后，给有站内展示权的题填 `use=licensed`、真实的 `rights_reference` 和含所需材料与图表的完整 `prompt`。含图或材料的真题须随题完整展示，或由有展示权的源链接提供题面。服务拒绝未带授权依据的题面。
2. 在可持久化的私有目录运行服务。用 HTTPS 反向代理公开 `/mcp`，保留原始 Host。SQLite 首版使用单个服务实例和持久化磁盘，快照或备份需按同样的数据权限与保留规则管理。运维可定期执行 `DELETE FROM drafts WHERE expires <= unixepoch()` 清理已过期暂存；过期内容在工具中立即失效。
3. 连接经批准的 OAuth 授权服务。配置以下变量，身份以已验签的 `iss + sub` 为准。当前实现接受 RFC 9068 风格的 `RS256` 访问令牌，需要 `typ=at+jwt`、匹配的发行方和 MCP audience、`client_id`、`exam-coach` scope，以及由授权服务核实后签发的布尔字段 `exam_coach_entitled=true`。不要把购买状态、用户名或账号 ID 当作工具参数。若 WorkBuddy 实际发的是不透明令牌或无法提供稳定主体，需要先接入受信的验证或绑定服务。
4. 执行 `exam-gap-coach` 启动服务。使用真实端点执行 `python build_expert.py --mcp-url https://你的域名/mcp --output /路径/exam-gap-coach.zip`。ZIP 内嵌的是指向本专家服务的 OAuth MCP 配置，无需另外寻找旧市场连接器。新专家的月订阅在 WorkBuddy 发布表单配置，ZIP 不控制支付。

| 配置 | 含义 |
| --- | --- |
| `EXAM_COACH_ISSUER` | 已批准的 HTTPS OAuth 发行方地址 |
| `EXAM_COACH_RESOURCE_URL` | 本专家的 HTTPS MCP 地址，与令牌 audience 及包内配置相同 |
| `EXAM_COACH_CLIENT_ID` | 允许签发此专家令牌的已注册 OAuth 客户端 ID |
| `EXAM_COACH_PUBLIC_KEY_FILE` | 发行方的 RSA 签名公钥文件 |
| `EXAM_COACH_DATABASE` | 档案数据库的持久化路径 |
| `EXAM_COACH_BANK` | 审阅并获商用许可的题库清单路径 |
| `EXAM_COACH_ALLOW_LINK_SAMPLES` | 仅隔离开发环境设为 `1` 启用原卷链接样例。真实付费实例不得设置 |
| `EXAM_COACH_PORT` | 本机监听端口，默认 8000 |

默认启动为生产模式。服务要求三科各有已授权题面，已上线考点至少有三道练习和两轮各三道的可用原卷题目，样例不会混入生产选题。学科、年级、地区或难度过滤后不足量时，服务照实返回题量。WorkBuddy 的购买、续费、退款与账号绑定入口需要拿实际付费资产预览验证，授权服务必须按验证过的权益签发短期访问令牌；当前仓库不代替平台支付，也不提供未接入的权益回调。家长或学生先授权再处理材料，档案中无原始照片。档案导出和删除只控制本服务的数据，WorkBuddy 会话附件按平台自己的存储规则处理。
